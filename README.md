# 流利蓝 · 暗色

Fluent 暗色：四档表面 + 亮蓝强调（主按钮是浅蓝底配深墨字，Fluent 暗色本家就是这么配的）

- 版本 / Version: `1.0.4`
- 作者 / Author: larix
- 标识 / ID: `uartix.theme.fluent-dark`
- 宿主 API / Host API: `^1.0`
- 能力 / Capabilities: `theme.tokens`

## 安装 / Install

在 Uartix+ 打开「设置 → 插件管理」→ 导入 `plugin.uartix.json`，或把包拖进应用窗口。
Import `plugin.uartix.json` in Uartix+ → Settings → Plugins, or drag the package into the app.
